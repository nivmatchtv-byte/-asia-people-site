# Asia People — сайт

Владелец: Ирина Носова (Дананг). Будущий адрес: asia-people.com.

- `index.html` — главный сайт: вкладки «Кластер» (креативный кластер моды и дизайна для администрации Дананга), «Бренд» (весь сайт Asia People: смысл, коллекция, цифры) и «Команда» (CEO, контакты). Одна ссылка на всё.
- `img/`, `hub/` — фотографии. `CNAME` — адрес для хостинга.
- Языки: RU / EN / VI, переключатель в шапке; `#en` или `#vi` в конце адреса открывает нужный язык.
